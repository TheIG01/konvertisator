В каком формате скачать?

Файл будет создан из текущего содержимого редактора.

Помощь

Все данные обрабатываются локально в браузере.

КлавишиДействие
Ctrl/Cmd + OОткрыть файл
Ctrl/Cmd + VВставить файл или текст
Ctrl/Cmd + SВыбор формата скачивания
Ctrl/Cmd + FПоиск в тексте
EscЗакрыть окна

Про направление «Из HTML». Когда вы вставляете HTML-код (например, готовый сайт или приложение), конвертер сохраняет оригинальный HTML. В превью вы видите его «как есть» — со стилями, скриптами и структурой. Скачивание .html (оригинал) возвращает ваш полный код без потерь. Скачивание .html (из Markdown) возвращает упрощённый текст — это полезно для сохранения только содержимого.

Изменения

Слева — исходный результат, справа — текущий текст.
